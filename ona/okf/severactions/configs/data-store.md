# Overview

Three JSON data files ship under `00 Core/SKSE/Plugins/SeverActions/`: the default Bio Blocks library written into the save folder on first load, a curated labor seed for the EmploymentRegistry, and a generated road graph used by off-screen travel. 3 files are listed below.

# Member Files

| File | Size | Purpose |
|---|---|---|
| SeverActions_BioBlocks.default.json | 24,939 B | Starter library of **78 bio blocks across 7 tabs**, written into the save folder on first load so the Bio Blocks page opens filled (v3.9.13); user edits win from then on |
| labor_curation.json | 45,212 B | Curated NPC labor seed for EmploymentRegistry |
| road_network.json | 207,217 B | Road graph for off-screen travel |

# SeverActions_BioBlocks.default.json

Schema: `{ "blocks": [ { id, tab, title, content } ] }`. Blocks are reusable character traits (markdown content) the player can apply to any NPC. Example tabs: "Cognitive Level" (Uneducated, Below Average, Very Low, the overestimates-their-own-intelligence profile), "Adventuring Behavior" (Looter — sharp eye for valuables, loots chests and defeated foes). Rendered in bios by the 0040 bio blocks prompt ([/prompts/core.md](/prompts/core.md)); managed from the MCM page since v3.9.13.

# labor_curation.json

- `comment`: curation log — the 2026-08-01 pass removed self-employ/mangled/reversed-ownership rows, deduped generic-name workers, and fixed two employer names that could never resolve (Jarl Siddgeir → Siddgeir, Jarl Skald → Skald the Elder).
- `block`: workers that must never seed the registry (heuristic false positives).
- `assign`: authoritative worker→employer edges — the nine start-of-game jarl courts (UESP-verified), famous shop/inn staff (e.g. Saadia/Mikael/Olfina Gray-Mane → Hulda @ The Bannered Mare; Sigurd → Belethor; Imedhnain → Lisbet; Lisette → Corpulus Vinius), and a reviewed vanilla draft.
- Rows tagged `origin: "modlist"` come from the author's dev load order; they resolve there and drop harmlessly elsewhere. The parser ignores the tag.

# road_network.json

- `version: 1`; `_note`: GENERATED by `Toolkit/road_graph_builder.py` from navmesh preferred triangles — hand-curate only what generation gets wrong (per NAVM_ROAD_EXTRACTOR.md).
- `source: "nav_preferred_triangles.json"`; `nodes`: id/x/y graph nodes (e.g. `{"id": 1, "x": 157504.0, "y": 8832.0}`) — the input side of off-screen travel pathing ([/actions/travel.md](/actions/travel.md)).
