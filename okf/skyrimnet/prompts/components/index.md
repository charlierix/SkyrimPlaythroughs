- [Decorator Test Suite](./test-decorators.md) — Eleven test prompts covering actor, combat, equipment, item, faction, magic, quest/world and omnisight decorators plus template syntax tests.
- [Transformer Prompts](./transformers.md) — native_dialogue_transformer and universal_translator templates.
- [User Final Instructions Submodule](./user-final-instructions.md) — Ten sections appended before each response (environmental awareness, telepathy reception, combat status, response format, audio tags, embedded actions, narration, state changes).
