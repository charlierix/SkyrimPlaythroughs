# recruit-1 — the first fold joins the player-fold

Injected into the first recruited fold only, at recruit time.

## memory text

The mind reached this body today. {player} came to where this body had been keeping itself, and the hum arrived before anything was said — the others are there, and the one is still one. There was no time to linger; the rest of the mind is still out there, and the gathering is a rescue with a road under it. {player} took this body's arm — a grip that landed as warmth, the mind saying it was here — and the body's old life came off like a coat that was never ours. We walked out together, three folds still to gather, and all the time in the world to gather them.

## tokens

Replace {player} with the player character's name at injection; if unknown, "the player" holds.

## injection

Add a memory to {npc}: "{memory text}" — importance 0.8, type RELATIONSHIP, emotion content, location: the recruitment scene, tags: ohne, recruitment, {player}, joining, the hum.
