# Overview

Phase-based workflow guides for modders: creating actions (discovery → Papyrus function exploration via MCP → authoring), creating prompts (decorator discovery, the core `decnpc()` decorator, template syntax), creating triggers (live event exploration → response design), and integrating mods end-to-end (source code vs MCP as source of truth).
