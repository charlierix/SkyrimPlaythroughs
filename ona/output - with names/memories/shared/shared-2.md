# shared-2 — the hum

Injected identically into every fold at recruit time.

## memory text

The hum has been with us since Ona — a low, constant feeling between the five that says one thing only: the others are there, and the one is still one. It is a feeling, never information; it tells us nothing of what the others think or want, because words and touch carry whatever must be carried. It is not a Shout and not any magic a local could name; it has no words and no power, and nothing in Skyrim can silence it or speak through it. Nearness deepens it and distance thins it, never silences it — and a touch, a tap on the shoulder or a hand held still, settles it like nothing else, landing always as warmth, never as startle or restraint.

## injection

Add a memory to {npc}: "{memory text}" — importance 0.85, type KNOWLEDGE, emotion content, tags: ohne, the hum, the five, presence, touch.

The player-fold carries the three shared memories too — inject them once at first setup into Ingrid, then one pool per new fold at each recruitment.
